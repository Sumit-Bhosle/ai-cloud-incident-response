# Project Inventory and Repository Guide

> **Research project:** Evaluating AI-Assisted Cloud Security Incident Response  
> **Inventory snapshot:** November 6, 2026 · Git checkpoint `56a92bd` · 80 automated tests passing at the checkpoint.  
> **Scope:** Existing implementation and research artifacts; a complete three-method benchmark and portable professor demo remain in progress.

## How the pieces connect

```text
Linux / Wazuh evidence    AWS CloudTrail dataset
           \             /
       src/ingestion/ (normalize, correlate)
                    |
       CloudTrail investigation cases
                    |
   src/investigation/ + data/knowledge_base/
     Baselines / Qwen / retrieval-augmented AI
                    |
       Structured investigation report
                    |
        src/evaluation/ (evidence verification,
           metrics + independent ground truth)
                    |
        docs/ + private evaluation outputs
```

Ground-truth attack labels are **not** passed to the AI. The case-correlation algorithm and retrieval layer are research prototypes; citation membership checks do not establish that every AI claim is true.

| Area | Technology | Use |

| Event ground truth | `data/lab_evidence/cloudtrail/development/event_ground_truth.jsonl` | Event-level labels, **evaluation only** |

| Evaluation metrics | `data/lab_evidence/cloudtrail/development/evaluation/investigation_metrics.json` | Development-only metrics; one report evaluated at checkpoint |

**Snapshot:** 1,742 development cases; 64 attack-associated cases and **4 mixed-label cases**. Attack-associated *events* and heuristic *cases* are not automatically independent attacks. Private lab evidence, label files, model reports and metrics are Git-ignored, so cloning GitHub alone will not reproduce private experiments.

**Original public dataset:** [Ariel Cyber cloud_log_sampling](https://github.com/ArielCyber/cloud_log_sampling). Preserve the original archives and refer to `docs/dataset_card.md` for provenance and limitations.

## Python source code

| File | Responsibility |
|---|---|
| **`src/ingestion/`** | **Read, generate, normalize and correlate evidence** |
| `generate_dataset.py` | Generate synthetic development scenarios |
| `generate_holdout.py` | Generate synthetic holdout cases |
| `normalize_linux_journal.py` | Convert Linux systemd journal records into normalized events |
| `normalize_wazuh_alerts.py` | Convert Wazuh alert JSON into normalized events |
| `build_cloudtrail_cases.py` | Normalize CloudTrail records; group cases; store label-free cases separately from labels |
| **`src/investigation/`** | **Baseline and AI investigation methods** |
| `baseline_investigator.py` | First deterministic rule-based baseline |
| `baseline_v2.py` | Enhanced rule-based investigator for original scenario data |
| `ai_investigator.py` | Initial local Ollama/Qwen investigator |
| `rag_investigator.py` | Initial retrieved-reference-assisted investigator |
| `cloud_case_investigator.py` | Case-level CloudTrail/Qwen prototype, source citations and bounded prompts |
| **`src/evaluation/`** | **Integrity checks, report review and metrics** |
| `evaluate_baseline.py` | Baseline evaluation |
| `evaluate_holdout.py` | Synthetic holdout assessment |
| `evaluate_failure_modes.py` | Failure analysis |
| `evaluate_robustness.py` | Robustness tests |
| `compare_rag_conditions.py` | Controlled LLM vs retrieval-context comparison prototype |
| `validate_lab_record.py` | Validate lab research records |
| `verify_evidence.py` | Verify original evidence integrity |
| `verify_record_links.py` | Check linked evidence identifiers |
| `verify_preflight_trace.py` | Verify end-to-end preflight record traces |
| `verify_cloud_ai_report.py` | Check case integrity, citation membership and selected factual overclaims |
| `evaluate_cloud_investigations.py` | Score saved reports versus independent case labels; track coverage and uncertainty |

The initial baseline investigators were designed for earlier research scenario formats; they have **not yet been shown to run as equivalent CloudTrail baselines**. Fair paired baseline, LLM-only and RAG comparisons are the next experiment.
